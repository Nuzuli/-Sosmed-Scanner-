# Changelog

All notable changes to this project are documented in this file.
The format follows Keep a Changelog.

## [Unreleased]

### Removed
- `Dockerfile` and the Docker section of the README. The project is a standard library command-line tool, not infrastructure code.

### Added
- "Project Type" section in the README.

## [0.3.0] - 2026-10-25

### Added
- Logging through the standard `logging` module, with a `-v/--verbose` flag for debug output on stderr.
- PyPI as a new platform.
- End-to-end integration tests covering the CLI, scanner, and network layers with a mocked HTTP call.
- `Dockerfile` for running the tool in an isolated container as a non-root user.
- Dependency audit with `pip-audit` in CI.
- `requirements-dev.lock`, generated by the manual "Update lockfile" workflow, for reproducible installs.
- Quick Start (fresh clone) and Docker sections in the README.

### Changed
- Invalid input is now reported as a logged `ERROR` message instead of a bare print.
- The User-Agent header now follows the package version.
- Updated pytest to 9.0.3 and pytest-cov to 7.1.0 to resolve a reported vulnerability in pytest.

### Fixed
- Error messages now keep the log format when the tool is started with `python -m sosmed_scanner.cli`.

## [0.2.0] - 2026-10-25

### Changed
- Rewrote the scanner into three focused modules: network, scanner, and CLI.
- Network errors are now reported as results instead of raised.
- Tests now use mocks and no longer require internet access.
- Development tools are pinned in `requirements-dev.txt`.

### Added
- `--platform` option to limit a scan to chosen platforms.
- `--json` output and `--delay` option.
- Username validation and exit code `2` for invalid input.
- CI with ruff, mypy, and pytest with an 80 percent coverage gate.
- Grouped monthly Dependabot updates.
